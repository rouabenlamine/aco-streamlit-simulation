# ACO Step-by-Step Visualizer

Educational Streamlit app in French demonstrating Ant System (ACO) on a four-city Traveling Salesman Problem.

## Files
- `app.py` — complete Streamlit app
- `requirements.txt` — Python dependencies

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt` to the repository root.
3. Visit https://share.streamlit.io/ and sign in with GitHub.
4. Click **Create app** / **Deploy an app**.
5. Select your repository, branch (`main`), and main file path (`app.py`).
6. Deploy.

The app uses a fixed distance matrix for a classroom demonstration. You can adjust the number of ants, iterations, alpha, beta, evaporation rate, deposit constant, and random seed from the sidebar.
